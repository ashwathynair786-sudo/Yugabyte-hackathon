ContextCon:Remember everything

is a worldwide virtual hackathon for developers building the next generation of agentic apps.

Most AI agents start from zero every session and can’t share what they’ve learned. With Meko, the self-learning context engine built on YugabyteDB, you’ll build agents with collective memory, shared knowledge, and full decision traces.

They connect through a single MCP endpoint to the tools you already use, like Claude, Cursor, Codex, LangChain, and CrewAI.

Start free, build from anywhere, and show what happens when one agent’s learning becomes every agent’s advantage.
